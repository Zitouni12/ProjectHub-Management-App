# 🧩 ProjectHub – Full-Stack Application (Spring Boot & React)

**ProjectHub** est une application web full-stack de gestion collaborative de projets.  
Elle permet de créer, suivre et organiser des projets et tâches au sein d’une équipe, avec une interface moderne et un backend robuste.

---

## 🚀 Fonctionnalités principales
- Création et gestion de projets et de tâches  
- Authentification et gestion des utilisateurs  
- Interface utilisateur réactive et ergonomique  
- Communication entre le frontend React et le backend Spring Boot via API REST  
- Conteneurisation complète avec **Docker** et **Docker Compose**  
- Base de données relationnelle (MySQL) pour la persistance des données  
- Tests unitaires backend (JUnit)

---

## 🛠️ Stack Technique

**Frontend :**
- React.js  
- Axios  
- Material UI  
- React Router  

**Backend :**
- Java 17  
- Spring Boot 3  
- Spring Data JPA  
- Spring Web  
- Spring Security (JWT)  
- MySQL  

**DevOps & Outils :**
- Docker & Docker Compose  
- Git & GitHub Actions  
- Maven  
- JUnit / Mockito
